# DWG Sheet Scanner — бесплатный автономный PDF

Программа создаёт PDF из DWG автономно. При выборе папки автоматически
включается объединение: в папке результата сохраняется один общий PDF
с закладками на каждый DWG. Промежуточные PDF удаляются автоматически.
Для отдельных PDF можно отключить объединение в интерфейсе.

Под очередью расположена небольшая зелёная полоса с процентом, текущим
этапом и временем работы. Прогресс обновляется внутри листов и при
объединении PDF; поиск DWG в папке выполняется в фоне.
Процент оценивает выполненные этапы, а не оставшееся время.

## Как это работает

```
DWG -> ODA File Converter -> временный DXF -> ezdxf/PyMuPDF -> векторный PDF
```

ODA File Converter — бесплатная автономная утилита для чтения закрытого DWG;
она нужна только для преобразования во временный DXF и не открывает окно CAD.
PDF создаётся локально, без виртуального принтера и без растрирования.

1. Готовые листы `Layout` печатаются в порядке вкладок с сохранёнными размером
   бумаги, поворотом, масштабом и размещением объектов. Содержимое видовых
   экранов из модели также выводится и добавляется в поисковый слой.
2. В `ModelSpace` программа находит блоки рамок с `ЛИСТ`/`РАМК`/`SHEET`/`FRAME`
   и `A0`--`A4`, включая дополнительные форматы (`А4х4`, `А2х3` и другие).
   Формат выбирается по имени рамки, а не по масштабу модели. Книжная и
   альбомная ориентация сохраняются. Произвольные размеры бумаги из Layout
   сохраняются в миллиметрах.
3. Каждый лист добавляется отдельной страницей в PDF.
4. Линии и поддерживаемая графика остаются векторными. Текст выводится
   приложенным TTF и дополняется скрытым Unicode-слоем в координатах исходной
   надписи — его можно искать и выделять в PDF-просмотрщике.

## Установка и запуск

1. Установите бесплатный [ODA File Converter](https://www.opendesign.com/guestfiles/oda_file_converter?language=en).
   В интерфейсе укажите путь к `ODAFileConverter` / `ODAFileConverter.exe`.
   Можно вместо этого задать переменную окружения `ODA_FILE_CONVERTER` или
   добавить программу в `PATH`.

   Вместо ручной установки есть кнопка «Скачать ODA для этой ОС». На Linux она
   скачивает официальный AppImage в пользовательскую папку и сразу подключает
   его. На Windows она скачивает и открывает официальный MSI; после завершения
   установки нажмите «Найти ODA».
2. Установите Python 3.11+ и зависимости:

   ```bat
   py -3 -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   .venv\Scripts\python main.py
   ```

3. Добавьте DWG и/или папки, проверьте поле со шрифтами, оставьте включёнными
   нужные источники листов и нажмите «Сканировать и создать PDF».

В комплекте автоматически выбран `assets/GOST2304A.ttf` (GOST 2.304
type A). В поле можно выбрать несколько TTF/OTF/SHX через `;` — для результата
максимально близкого к источнику передайте именно шрифты, использованные в DWG.

Для пакетного запуска:

```bat
python batch_convert.py "C:\Проекты\Альбом DWG" --output "C:\Проекты\PDF" --oda "C:\Program Files\ODA\ODAFileConverter\ODAFileConverter.exe" --font "C:\Шрифты\GOST2304A.ttf" --merge
```

## Готовые сборки для Windows и Linux

Приложение кроссплатформенное: одинаково работает с DWG на Windows и Linux.
Однако исполняемые файлы ОС несовместимы, поэтому они собираются отдельно:

- Linux: `bash build_linux.sh` создаёт `dist/DWG_Sheet_Scanner/DWG_Sheet_Scanner`.
  Для сборки нужен Python с `tkinter` (в Ubuntu: пакет `python3-tk`).
- Windows: на Windows запустите `build_windows.bat`; появится
  `dist\DWG_Sheet_Scanner\DWG_Sheet_Scanner.exe`.

В обе версии уже вложен `GOST2304A.ttf`. Обычная сборка не содержит ODA.
Можно указать путь к уже установленному конвертеру или разместить полную папку
ODA рядом с EXE: `DWG_Sheet_Scanner/ODA/ODAFileConverter.exe`. Программа
автоматически находит этот вариант прежде установленного ODA.

Переносимый Windows ZIP с предоставленным ODA создаётся после сборки:

```bat
.venv-build\Scripts\python package_windows_portable.py --oda-dir "C:\Program Files\ODA\ODAFileConverter 27.9.0"
```

Скрипт добавляет все файлы ODA и библиотеки Visual C++ Runtime x64 рядом с ним.
Пользователям не нужен установщик или права администратора. Всю папку можно
держать на общей сетевой папке, если политика организации разрешает запуск
программ оттуда. Каждый процесс выполняет конвертацию на ПК пользователя;
общая папка сама по себе не является сервером обработки.

Используйте этот способ только при наличии прав на сторонние компоненты.
[FAQ ODA](https://www.opendesign.com/faq/question/what-are-oda-viewer-and-oda-file-converter)
ограничивает применение бесплатных приложений пользователями вне членства ODA
некоммерческими задачами. Для рабочего отдела уточните права организации у ODA.
Сторонние бинарные файлы не публикуются в Git и ZIP исходников.

Подробная проверка на Windows: [WINDOWS_QUICKSTART.md](WINDOWS_QUICKSTART.md).

## Ограничения, которые важно знать

Бесплатный путь корректно сохраняет формат листа, векторную геометрию и
доступные TTF-шрифты. Однако невозможно честно обещать попиксельное `1:1`
для любого DWG, если не переданы исходные TTF/SHX или в чертеже есть
proxy-объекты, Xref, нестандартные CTB/STB и не поддерживаемые DXF-сущности.
Поэтому перед передачей заказчику нужно визуально сверить контрольные листы
каждого нового семейства чертежей. Предоставленный GOST-шрифт уже подключён;
для остальных корпоративных стилей нужны их исходные файлы.

## Структура

- `main.py` — запуск графической оболочки;
- `dwg_pdf/headless.py` — бесплатный конвейер, поиск листов, векторный рендер
  и позиционный поисковый слой;
- `dwg_pdf/service.py` — последовательная очередь и объединение PDF;
- `batch_convert.py` — пакетный запуск без GUI;
- `assets/GOST2304A.ttf` — приложенный шрифт ГОСТ.
