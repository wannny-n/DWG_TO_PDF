# Контракт нативного ODA PDF-экспортёра

## Зачем он нужен

Требование «DWG и PDF 1:1» не должен выполнять Python-рендерер. Production
экспортёр собирается с лицензируемым ODA Drawings SDK и использует его
OdPdfExport напрямую. Он запускается без nanoCAD и без пользовательского
интерфейса CAD.

ODA Drawings SDK поддерживает PDF-экспорт, TTF/SHX и выбор частей чертежа.
Для ModelSpace экспортёр должен выбирать top-level объекты внутри каждой
найденной рамки до рендеринга, а не рисовать весь чертёж и затем обрезать его.

## Вызов

    dwg_native_pdf_exporter
      --source <входной.dwg>
      --output <итоговый.pdf>
      --result <результат.native-result.json>
      --include-layouts 0|1
      --include-model-frames 0|1
      --font <TTF/SHX> [--font <TTF/SHX> ...]

Правила:

1. Один исходный DWG создаёт ровно один многостраничный PDF.
2. Каждый Layout становится одной страницей с его page setup.
3. Каждая подтверждённая рамка ModelSpace становится отдельной страницей.
   Формат берётся из имени/атрибута рамки или установленного формата Layout,
   а не по масштабу геометрии.
4. Подключаются все переданные TTF/SHX и пути из DWG, Xref, CTB/STB.
5. Текст должен оставаться текстовыми объектами PDF, где это разрешает
   исходный шрифт. Если конкретный объект неизбежно превращён в кривые,
   экспортёр добавляет ему невидимый Unicode-слой в тех же координатах.
6. В stdout/stderr пишется журнал, код 0 означает только успешный экспорт.

## JSON-результат

После успешного запуска экспортёр записывает UTF-8 JSON:

    {
      "success": true,
      "output_pdf": "C:\\output\\drawing.pdf",
      "sheet_count": 3,
      "formats": ["A2", "A2", "A1"],
      "message": "..."
    }

При ошибке поле success равно false, output_pdf может отсутствовать, а message
обязателен. Python-оболочка не примет PDF без этого подтверждения и отдельной
проверки числа страниц/поискового текста.

## Склейка выбранных DWG

После нативного экспорта каждого DWG Python-оболочка склеивает уже готовые
векторные документы в All_Selected_DWG.pdf. Повторной печати и растеризации
при склейке нет.
