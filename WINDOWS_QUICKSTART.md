# Проверка DWG Sheet Scanner в Windows

## 1. Получить исходники

На странице GitHub-репозитория нажмите **Code → Download ZIP**, распакуйте
архив, например в `C:\Projects\DWG_TO_PDF`.

## 2. Установить Python

Установите 64-битный Python 3.11 или новее с [python.org](https://www.python.org/downloads/windows/).
При установке включите опцию **Add Python to PATH**.

Откройте `cmd` в папке проекта и проверьте:

```bat
py --version
```

## 3. Собрать Windows-приложение

Дважды щёлкните `build_windows.bat` или выполните:

```bat
cd /d C:\Projects\DWG_TO_PDF
build_windows.bat
```

По завершении появится:

```text
dist\DWG_Sheet_Scanner\DWG_Sheet_Scanner.exe
```

## 4. Первый запуск и ODA

Откройте `DWG_Sheet_Scanner.exe`. Не переносите `.exe` отдельно: папка
`_internal` рядом с ним обязательна.

1. Нажмите **Скачать ODA для этой ОС**.
2. Подтвердите скачивание, затем обычный установщик Windows/UAC.
3. После установки вернитесь в программу и нажмите **Найти установленный ODA**.
4. Поле `ODA File Converter` должно заполниться путём к `ODAFileConverter.exe`.

ODA скачивается с официального сайта по HTTPS.

## 5. Первый экспорт

1. В поле шрифтов уже указан `GOST2304A.ttf`.
2. Нажмите **Добавить DWG…**.
3. Выберите свой DWG-файл или папку с DWG-файлами.
4. Выберите папку результата.
5. Нажмите **Сканировать и создать PDF**.

В строке состояния должен появиться результат без ошибок; в PDF должен
находиться текст по Ctrl+F.

## Если что-то не получилось

- Кнопка «Найти установленный ODA» ничего не нашла — укажите
  `ODAFileConverter.exe` вручную через кнопку «Выбрать…».
- Надписи отличаются от исходника — добавьте в поле «CAD-шрифты» оригинальные
  TTF/OTF/SHX проекта.
- SmartScreen предупреждает о неизвестном приложении — это ожидаемо для
  неподписанной локальной сборки; проверьте исходники и соберите `.exe` сами
  через `build_windows.bat`.
