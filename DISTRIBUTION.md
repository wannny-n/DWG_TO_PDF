# DWG Sheet Scanner — запуск готовой сборки

## Linux x86_64

Распакуйте архив и выполните из папки приложения:

```bash
./DWG_Sheet_Scanner
```

Если ОС блокирует запуск, выдайте право на выполнение:

```bash
chmod +x DWG_Sheet_Scanner
```

## Windows x64

Запустите `DWG_Sheet_Scanner.exe` из распакованной папки. Не переносите только
`.exe`: рядом должна остаться папка `_internal`.

## Один раз на каждой ОС

Установите ODA File Converter и укажите путь к нему в первом поле приложения
или добавьте его в `PATH`. Он не входит в архив, поскольку является отдельной
программой для чтения DWG. nanoCAD не требуется.

В архив уже включён `GOST2304A.ttf`. Если конкретный проект использует другие
TTF/OTF/SHX, добавьте их в поле «CAD-шрифты» перед экспортом.
