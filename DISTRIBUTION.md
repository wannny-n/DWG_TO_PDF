# DWG Sheet Scanner — запуск готовой сборки

## Linux x86_64

Распакуйте архив и выполните из папки приложения:

```bash
./DWG_Sheet_Scanner
```

Если ОС блокирует запуск, выдайте право на выполнение:

```bash
chmod +x DWG_Sheet_Scanner
```

## Windows x64

Запустите `DWG_Sheet_Scanner.exe` из распакованной папки. Не переносите только
`.exe`: рядом должна остаться папка `_internal`.

## Один раз на каждой ОС

Установите ODA File Converter и укажите путь к нему в первом поле приложения
или добавьте его в `PATH`. Он не входит в архив, поскольку является отдельной
программой для чтения DWG.

На Windows установленный ODA обнаруживается автоматически, в том числе в
папках с номером версии. Результаты по умолчанию сохраняются в
`Documents\DWG_PDF` вашего пользователя.

Пакетная обработка готовой сборкой:

```bat
DWG_Sheet_Scanner.exe --batch "C:\Чертежи" --output "C:\PDF" --merge
```

Журнал пакетного запуска находится в `conversion.log` в папке результата.
При выборе папки в интерфейсе включается объединение всех DWG в один PDF.
При включённом объединении отдельные PDF не остаются в папке результата.

Печатаются объекты модели и готовые листы (Layout) с видовыми экранами.
Поддерживаются удлинённые форматы, например А4×4 (297×841 мм), произвольные
размеры бумаги в Layout, а также книжная и альбомная ориентация.

Под очередью отображаются зелёная полоса готовности, проценты, текущий этап
и время обработки. На больших листах процент может некоторое время
оставаться на месте; строка показывает этап, а счётчик времени продолжает
обновляться. Поиск DWG в папке не блокирует окно.

В архив уже включён `GOST2304A.ttf`. Если конкретный проект использует другие
TTF/OTF/SHX, добавьте их в поле «CAD-шрифты» перед экспортом.
